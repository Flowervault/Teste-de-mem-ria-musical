# Teste de ouvido (Android)

Pop-up flutuante sobre outros apps para marcar acerto/erro/anula de nome, álbum e artista.
Os resultados ficam só no celular (nada de nomes de música).

## Gerar o APK (escolha um)
1. Android Studio (computador): File > Open > escolha esta pasta > espere sincronizar > Build > Build APK(s).
   O arquivo sai em app/build/outputs/apk/debug/app-debug.apk
2. GitHub: crie um repositório, envie todo o conteúdo desta pasta (inclusive .github) na branch main.
   Aba Actions > Build APK > baixe "teste-de-ouvido-apk" no final.

## Instalar e usar
- Instale o app-debug.apk (permita "fontes desconhecidas" quando o Android pedir).
- Abra o app > Abrir pop-up > ative "Exibir sobre outros apps" > volte e toque de novo em Abrir pop-up.
- Arraste o pop-up pela faixa de cima. Toque numa bolinha para escolher acerto, erro ou anula.
